# Agent Memories

Create a short kebab-case Markdown file here when difficult work reveals a verified fact that
will prevent future investigation or mistakes. Do not create routine work logs.

Each memory should contain:

```markdown
# Descriptive title

Last verified: YYYY-MM-DD
Relevant paths: `relative/path`, `another/path`

## Finding

The durable fact or hidden constraint.

## Why it matters

The symptom, risk, or decision this explains.

## How to verify

The smallest inspection or command that confirms the finding.
```

Keep evidence reproducible and repository-relative. Link a related skill if the solution is a
repeatable workflow. Promote anything users must know into normal documentation.
